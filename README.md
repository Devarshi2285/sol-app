# 🌌 Sol App

An Angular-based web app integrating **Solana** tooling and modern frontend utilities.

## ✨ Highlights
- Angular 21 application
- Solana Web3 + Anchor libraries
- Ready for wallet + chain integrations

## 🛠️ Tech Stack
- **Angular**
- **TypeScript**
- **Solana Web3.js**
- **Anchor**

## 🚀 Getting Started
```bash
npm install
npm start
```

## 🔧 Useful Scripts
```bash
npm run start   # ng serve
npm run build   # production build
npm run test    # unit tests
```
